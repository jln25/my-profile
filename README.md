# My Profile
 
A one-page personal profile site built for MMS 171.
 
## Files
 
| File | What it does |
|---|---|
| `index.html` | The page structure and content |
| `style.css` | Colours, fonts, and layout |
| `projects.js` | Builds the Ongoing projects cards from `projects.xml` |
| `projects.xml` | The list of ongoing projects |
| `icons/` | Social media icons for the footer |
 
## Design
 
- **Colours:** teal `#36A8A8`, cyan `#50EBEC`, dark green `#1F271B`, and beige `#E9E1E1`
- **Fonts:** Merriweather for headings and Jost for body text, both from Google Fonts
